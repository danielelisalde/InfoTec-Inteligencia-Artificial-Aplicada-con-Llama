UAGro Orienta es un asistente inteligente para aspirantes de la Universidad Autónoma de Guerrero. Permite consultar carreras, localidades, modalidades, duración y datos de contacto mediante lenguaje natural. El sistema utiliza RAG para recuperar información real del catálogo de oferta educativa y Groq con Llama/GPT-OSS para generar respuestas claras. También se implementó un ajuste de tono mediante LoRA como parte del proceso del Hackathon. El prototipo fue probado con consultas sobre Chilpancingo, Acapulco, Taxco y Cuajinicuilapa.
